# APower Group

Website for APower Group, a heating, cooling and home appliance store at 131-31 Fowler Ave, Flushing, NY 11355. The store sells and installs mini-splits, heat pumps and air conditioners, and serves all five boroughs of New York City and Long Island.

## About the site

- One-page, mobile-friendly website
- Chinese and English, with Chinese as the default language
- Dark and light mode, with dark as the default
- Sections: services, products and brands, Mitsubishi Electric technology, heat pump rebates, about us, areas served, free quote, and store location and hours

## Built with

Plain HTML, CSS and JavaScript, with no frameworks or build step. Hosted on GitHub Pages.

```
index.html        page content
css/styles.css    styles and color themes
js/main.js        language toggle, theme toggle, menu and animations
images/           logo and photos
```
